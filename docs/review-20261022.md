# Software review fixes · 2026-10-22

This review addresses execution ownership, malformed prediction receipts, Excel export and source-package validation. It does not rerun existing studies or establish biological efficacy or safety.

## Execution ownership

Each new job attempt now records its physical host when claimed. Re-registering a worker name on another host cannot relocate the old attempt's cleanup hold or CPU/GPU reservation. Registration waits while claim admission and host binding complete. Attempts created before this change retain an unknown host; an unverified cleanup stays a conservative global hold.

The attempt ledger adds one nullable column, `platform_attempts.physical_host`. Normal service initialization applies this additive migration. For an operator-managed runtime that constructs `Queue(..., initialize=False)`, initialize the schema with the updated software and existing private configuration before starting updated workers:

```sh
skinpipe-platform --config /path/to/existing-runtime.json init
```

Use the installation's existing maintenance procedure; this review does not restart operating services. Do not infer an old attempt's host from a current worker registration or clear a cleanup hold without its own evidence.

A coordinator with an already-set shutdown event returns before claiming work. A shutdown arriving during claim is checked before research or export preparation starts.

## Scientific records and Excel

Malformed cached prediction containers no longer abort candidate processing. Known or metadata-declared classifier outputs must be finite and within their declared probability domain. Valid zero and negative regression values remain valid. Derived physicochemical properties alone do not establish learned ADMET predictions, and overlapping learned/computed endpoint names cannot overwrite each other.

Invalid receipts remain in saved source data and do not fill the representative-candidate quota. Extremely large recorded integers produce an explicit invalid-value label in Excel rather than aborting the entire workbook; their source values remain preserved.

## Public source packages

The source installer validates all archive paths and entry types before writing payload files. Duplicate paths, links and special files are rejected. Failed download archives receive unique preserved filenames, including retries within the same second.

The public package guard checks duplicate ZIP members, directory paths, file types, size limits and empty study templates. This repository continues to contain software, tests, documentation and reviewed public tutorial assets. Study inputs, results, databases, model weights and credentials are excluded. Pattern checks and an allowlist complement review; they do not guarantee detection of every possible secret.

## Regression coverage

The changes have focused reproductions covering host re-registration and claim concurrency with PostgreSQL, shutdown entry, malformed/classifier prediction receipts, preserved Excel values, and crafted local source archives. Browser regression fixtures use the current status-summary endpoints. The private test suite also retains its existing import-path and observable-assertion checks.

The existing installation and browser documentation remains the entry point. This review is not a new full Ubuntu installation qualification, a full catalog calculation, or a claim that every optional model and hardware combination has been tested.
