# SkinPipe

[English](README.md) · [브라우저 사용 순서](docs/browser.ko.md) · [설치·DB·모델 안내](docs/catalog.ko.md)

SkinPipe는 피부 연구용 화합물 스크리닝 플랫폼입니다. 화합물 이름·SMILES, 단백질 이름, 단백질–리간드 결합 구조 중 하나에서 시작합니다. 입력을 확인하고 분석한 뒤 후보 비교, 구조·피부·독성 평가 확인, Excel 내보내기까지 브라우저에서 진행합니다.

이 저장소는 소프트웨어와 설치 안내만 제공합니다. 연구 입력·분석 결과·화합물 DB·예측값·모델 가중치는 각 사용자의 별도 설치 폴더에 저장됩니다. 연구 이력과 사전 지정 표적은 빈 상태로 시작합니다.

## 한 번에 설치하고 실행하기

**Ubuntu 24.04 x86_64의 일반 사용자 계정**에서 실행합니다. sudo 권한, Python 3, 인터넷, **20 GiB 이상의 여유 공간**이 필요합니다. 시스템 패키지 설치 시 터미널에서 Ubuntu 비밀번호를 묻습니다.

Ubuntu 터미널에 아래 한 줄을 붙여 넣으세요.

```sh
python3 -c 'import urllib.request; exec(compile(urllib.request.urlopen("https://raw.githubusercontent.com/kangk1204/SkinPipe_public/main/install.py", timeout=30).read(), "SkinPipe installer", "exec"))'
```

공개 소스 → 앱·별도 ADMET 모델 환경 설치 → 공식 출처의 작은 화합물 목록 다운로드 → ADMET 계산 → 검색 인덱스 구축 → 앱 시작 순서로 진행합니다. 터미널에 **Ready**가 나오면 브라우저에서 **http://127.0.0.1:4317** 을 여세요. 실행 터미널은 열어 두세요.

**최초 준비는 오래 걸립니다.** 모델·패키지를 처음 내려받고 ADMET과 검색 인덱스를 만들기 때문입니다. 터미널의 단계와 로그 위치로 진행 상황을 확인합니다. 기본값 `--device auto`는 NVIDIA GPU의 실제 계산을 검사해 사용하고, 사용할 수 없으면 CPU로 진행합니다. 도킹은 설치한 CPU Vina 엔진을 사용합니다. GPU 드라이버를 설치하거나 변경하지 않습니다.

기본 DB는 사용법을 익히기 위한 **작은 starter 목록**입니다. 전체 라이브러리는 검색 범위가 더 넓지만 **300 GiB 이상**의 공간이 필요하며 CPU 계산은 **수일 이상** 걸릴 수 있습니다. [출처·이용조건·전체 구축 방법](docs/catalog.ko.md)을 먼저 읽어 주세요. 이 저장소에서 미리 계산한 DB를 내려받는 방식이 아닙니다.

macOS·Windows는 Ubuntu 서버에 설치한 뒤 [SSH 터널로 접속](docs/catalog.ko.md#macoswindows의-브라우저에서-접속)합니다. 이 설치기는 macOS·Windows에 직접 설치하는 프로그램이 아닙니다.

## 첫 연구 진행하기

1. **새 연구 시작**을 엽니다.
2. **화합물을 알고 있어요 / 단백질을 알고 있어요 / 결합 구조가 있어요** 중 하나를 선택합니다.
3. 이름·SMILES·PDB ID·구조 파일을 넣고 **입력 확인하기**를 누릅니다. 분자 구조, 생물종, 결합 화합물과 포켓을 확인합니다. 모호한 이름은 정확한 대상을 선택해야 합니다.
4. 탐색 방식과 피부 연구 조건을 정합니다. 모르는 제형·농도는 비워 둡니다. 계산 한도를 확인하고 **새 연구 실행**을 한 번 누릅니다.
5. 실행 단계와 경과 시간을 확인합니다. 접수 후 다른 화면을 열어도 연구는 저장됩니다. 실행 기록의 **진행·결과 보기**로 돌아올 수 있습니다.
6. 후보를 비교하고 **2D 구조**, 저장된 **3D 자세**, 피부·독성 상세를 확인합니다. **Excel 받기**를 누릅니다. 대량 결과는 **Excel 묶음 ZIP**을 풀어 통합문서를 여세요.

[전체 브라우저 안내](docs/browser.ko.md)에 세 입력 모드, 취소·재개, 결과 개수, 필터, 구조, 여러 연구 내보내기, 선택적 ChatGPT 사용 순서를 정리했습니다.

## 다시 실행·종료·진행 확인

설치 후 다시 실행:

```sh
bash ~/SkinPipe/runtime/Start-SkinPipe.sh
```

다른 터미널에서 로컬 앱과 앱이 관리하는 작업 종료:

```sh
bash ~/SkinPipe/runtime/Stop-SkinPipe.sh
```

최초 DB 구축 진행 확인:

```sh
bash ~/SkinPipe/runtime/Catalog-Status.sh
```

`Prepare-Catalog.sh`가 만들어진 뒤 DB 구축이 중단됐다면 같은 설치 명령·옵션으로 재개합니다. 저장한 구축 기록을 이어 사용하며 두 번째 구축을 띄우지 않습니다. 그 전에 패키지 설치가 실패하면 로그를 보존하고 새 설치 폴더로 재시도하는 방법을 안내합니다. 준비 완료 후 앱을 다시 켜는 것만으로 전체 ADMET을 재계산하지 않습니다.

브라우저의 **설치 상태 확인**에서 DB·인덱스·모델·도킹 엔진을 점검할 수 있습니다. [파일 위치와 문제 해결](docs/catalog.ko.md)도 참고하세요.

## ChatGPT 연결은 선택

기본 탐색·로컬 예측·결과·Excel은 ChatGPT 없이 동작합니다. **ChatGPT 연결 (선택)**에서 계정을 연결하고 **문헌 검토**에서 공개 문헌을 검토합니다. 입력 안내와 결과 설명에는 해당 연구에서 전달을 허용한 자료만 사용합니다.

모델 목록에 있으면 `gpt-6-luna` · `max`를 먼저 선택합니다. Luna가 없으면 제공자가 명시한 기본 모델을 사용하며, 기본 모델도 없으면 사용자가 목록에서 선택합니다. 호출 실패 후 다른 모델이나 별도 API 과금으로 자동 전환하지 않습니다. 사용할 수 있는 모델과 사용량은 연결한 계정에 따라 다릅니다. [연결·자료 전달 안내](docs/browser.ko.md#선택적-chatgpt-사용)를 확인하세요.

개발용 검사 명령과 기여 규칙은 [영문 README](README.md#development)와 [CONTRIBUTING.md](CONTRIBUTING.md)에 있습니다. SkinPipe 배포 라이선스는 추후 결정합니다. 포함된 외부 구성 요소는 각자의 고지를 유지합니다.
